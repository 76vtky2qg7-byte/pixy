## Сделано

### Ядро
- Симуляция на чистом TypeScript, без Phaser и DOM: фиксированный шаг 60 Гц,
  пространственный хэш, пулы объектов — за волну ничего не аллоцируется.
- Панель 2×3: модули действуют только на соседей **по стороне** и только на
  оружие. Граф эффектов двудольный и глубиной в один уровень, поэтому
  бесконечный цикл усиления невыразим, а разрешение — один проход.
- 6 видов оружия с разным поведением (одиночный снаряд, орбита, цепь, навес,
  луч, удар по кругу), 8 модулей, 8 названных сочетаний.
- 6 типов врагов с разным ИИ, 2 босса с фазами по HP и телеграфом атак.
- 3 контракта (6/7/8 волн), 2 корпуса робота, 8 постоянных улучшений.
- Перегрев оружия, Разгон, воскрешение (за постоянное улучшение).

### Платформа и данные
- Адаптер Яндекс SDK по документированной поверхности `@types/ysdk`. Любой сбой
  деградирует в «недоступно», игра не блокируется.
- Менеджер пауз с независимыми причинами (`menu`, `ad`, `hidden`, `system`,
  `boot`). Закрытие рекламы не возобновляет скрытую вкладку.
- Сохранения: версия, валидация, миграция, разрешение конфликта локального и
  облачного по `revision` — балансы **никогда не суммируются**.
- Награды за волну идемпотентны по индексу волны: перезагрузка не начисляет
  премию дважды.
- Аналитика: 8 событий, идентификатор попытки и версия баланса, без
  персональных данных. Сборщик не подключён — это указано явно.
- Покупки реализованы как отключаемая возможность: без настроенного каталога
  раздел не отображается вовсе.

### Представление
- Phaser рисует симуляцию; весь интерфейс — DOM, поэтому кириллица чёткая и
  кнопки настоящие.
- Целочисленный масштаб пикселей, выбранный по короткой стороне экрана: портрет
  и ландшафт видят одинаковый объём мира по этой оси, спавн одинаково честен.
- Управление: WASD/стрелки по физическим кодам (работает на кириллице),
  плавающий джойстик под большим пальцем, корректная обработка `pointercancel`,
  потери фокуса и скрытия вкладки.
- Звук синтезируется в Web Audio — ни одного аудиофайла в сборке.
- Обучение внутри первого контракта, привязанное к реальным событиям.

### Графика
- Вся графика генерируется кодом (`tools/genart.mjs`), 36 КБ на всё.
  Генератор детерминирован: повторный запуск даёт побайтово те же файлы.
- Единая палитра, единый масштаб пикселя, фон менее контрастный, чем объекты.

## Принятые решения

| Решение | Причина |
|---|---|
| Симуляция отделена от Phaser и DOM | Позволяет гонять тысячи волн headless в харнессе баланса и покрывать боевую математику модульными тестами. |
| Интерфейс на DOM, а не на канвасе | Кириллица, реальные размеры кнопок, отсутствие обрезанного текста при любом размере окна. |
| Целочисленный масштаб от короткой стороны | Пиксель-арт остаётся чётким; обе ориентации видят одинаковый объём мира. |
| Модули влияют только на оружие | Единственное ограничение, которое делает правило объяснимым одной фразой и делает бесконечный цикл структурно невозможным. |
| Награды идемпотентны по индексу волны | Перезагрузка в середине контракта не должна оплачивать волну дважды. |
| Конфликт облака решает игрок | Суммировать два снимка кошелька — значит выдумать валюту. |
| Пауза берётся при **открытии** рекламы | Реклама, которой нет, не должна морозить игру. |
| Mock-платформа только в dev-сборке | Релиз не может имитировать успешную монетизацию. |
| `window.__app` есть и в релизе | Браузерные проверки гоняют **реальный** артефакт, а не специальную сборку. Ничего секретного не открывает. |
| Playwright не в зависимостях проекта | npm 10.9.7 ломается на графе опциональных peer-зависимостей vitest+playwright; и это инструмент проверки, а не зависимость игры. |

## Ошибки, найденные и исправленные

Полный список с причинами — в `TEST_REPORT.md`. Кратко: 4 ошибки отрисовки,
которые не заваливали ни один тест и были видны только глазами (мусор вместо
пола, залитые шкалы нагрева, заметное повторение плитки, шкала здоровья во всю
ширину экрана); 4 ошибки жизненного цикла, пойманные сквозными проверками
(двойное монтирование экранов, молча умирающее обучение, нулевая награда за
проигранную первую волну, зависание на 45 секунд при молчащем SDK); 5 проблем
баланса, найденных харнессом (плоская броня, недоджабельные удары босса,
ненаходимый просвет в залпе, слишком крутое масштабирование, теряемый лом).

## Проверено

- **129 модульных тестов** — соседство, экономика, сохранения, менеджер пауз и
  жизненный цикл рекламы (25 сценариев: длинный ролик, поздний `onOpen`,
  наложение запросов, запоздалые callback, повторные награды).
- **66 сквозных проверок** production-сборки в Chromium с подставным SDK,
  включая все исходы рекламы, 20 переходов волна→магазин→итоги, перезагрузку в
  середине контракта, `pointercancel`, смену языка и размера окна.
- **Запуск из распакованного ZIP по вложенному пути** — меню, контракт, волна,
  шрифт с кириллицей, ноль ошибок консоли.
- **FPS замерен**: 60 при обычной игре, 58–60 при удержании на потолке в 90
  врагов. Условия замера описаны в `TEST_REPORT.md` — это headless Chromium с
  программным рендерингом, не телефон.
- **Сборка воспроизводится из чистого клона**: `npm ci` → `npm run build` →
  `npm test` → `node tools/pack.mjs`.
- **Офлайн проверен**: после загрузки страницы все экраны открываются и волна
  играется при отключённой сети, без единого неудачного запроса.
- **Видео записано**: два ролика по 34 с (портрет 390x844 и десктоп 1366x768) —
  настоящая запись собранной игры, ввод идёт через обычный тач-путь, джойстик
  виден на экране. Ранее я ошибочно сообщил, что запись недоступна, не проверив
  это.

- **Три предполётных аудита** (`npm run audit:static`, `audit:browser`,
  `audit:iframe`) — без замечаний. Проверяют то, что видно модератору раньше
  всего: вёрстку на 10 размерах экрана в двух языках (120 сочетаний), шрифт,
  кнопки без эффекта, ошибки консоли, запросы за пределы источника, а также
  игру внутри по-настоящему стороннего iframe — в том числе с полностью
  заблокированным хранилищем.

## Проверка перед модерацией

Что удалось проверить механически — и что нет.

**Найдено и исправлено этим прогоном:**

- **В шрифте не было букв `О` и `П`.** Не ошибка нарезки: в самом выпуске
  Pixelify Sans нет глифов U+041E и U+041F. Слова «ОПАСНО», «ПОБЕДА»,
  «ОТМЕНА», «ПАУЗА» набирались с системной засечкой посреди слова. В CSS
  диапазон был объявлен, поэтому по стилям это не ловилось — только отрисовкой.
  Недостающие глифы построены из уже имеющихся (`О` — латинская `O`, `П` — `п`,
  поднятая до высоты прописных), добавлены `→`, `✔`, `★`.
  См. `tools/genfont.py` и `ASSET_LICENSES.md`.
- **Заголовок страницы был `Искролом / Sparkscrapper`** — одно название через
  слэш читается как два. Теперь следует языку интерфейса и совпадает с
  названием на карточке и в меню.
- **На обложке `С` читалась как `О`**: сплошная тень со сдвигом 5px закрывала
  просвет буквы, и название читалось как «ИОКРОЛОМ». Тень укорочена и затемнена.

**Проверить может только владелец аккаунта:**

- Свободно ли название «Искролом» / «Sparkscrapper» в каталоге Яндекс Игр.
  Каталог из этого окружения недоступен. Общий поиск в интернете совпадений не
  дал, но это **не** проверка каталога.
- Предельные размеры полей формы и требуемые размеры картинок.
- Всё остальное из списка ниже.

**О чём здесь не утверждается ничего:** ни о публикации, ни о прохождении
модерации, ни о проверке на реальных устройствах. Ничего из этого не делалось.

## Исправлено после внешнего ревью

| Было | Стало |
|---|---|
| SDK грузился с `https://yandex.ru/games/sdk/v2` | `/sdk.js` — корневой путь платформы для ZIP-сборки. Упаковщик проверяет, что сборка ссылается именно на него. |
| Пауза снималась по таймеру в 45 с | Пауза привязана к тому, видна ли реклама: `onOpen`/`onClose`, счётчик открытых показов. Ролик любой длины держит паузу. |
| Поздний `onOpen` навсегда замораживал игру | Поздний показ корректно ставит и снимает паузу. |
| Завершённый запрос отпускал защиту от наложения | Запрос — это сессия; новая реклама не открывается поверх видимой. |
| Запоздалые callback старого запроса влияли на новый | Каждая сессия отвечает только за себя. |
| Молчащий хост навсегда блокировал кнопку рекламы | После окна ожидания разрешён повтор, при этом поздний показ всё ещё обрабатывается. |
| Карточка обещала работу без интернета — это было неправдой | Экраны предзагружаются, мелкие спрайты встроены; офлайн проверен и теперь работает. |
| Предел размера считался 20 МБ | 100 МБ — предел платформы (со слов ревью), 20 МБ — собственная цель. |

## Осталось (требует владельца аккаунта)

Полный порядок — в `store/OWNER_CHECKLIST.md`.

1. **Проверить инициализацию SDK в черновике.** Адрес `/sdk.js` существует
   только на платформе, отсюда он ни разу не запрашивался. Это первое, что
   нужно увидеть работающим.
2. Прочитать актуальные требования Яндекса — из этого окружения `yandex.ru` и
   `yandex.com` заблокированы сетевой политикой, страницы не читались ни разу.
   Сверить предел размера архива и требуемые размеры картинок карточки
   (фактические размеры готовых файлов — в `store/MEDIA.md`).
3. Проверить доступность названия «Искролом» / «Sparkscrapper» в каталоге.
4. Проверить рекламу на живом инвентаре: заполняемость, реальное закрытие,
   поведение при блокировщике.
5. При желании включить покупки: создать каталог с `foreman_kit` и
   `no_forced_ads`; до этого раздел покупок скрыт автоматически.
6. Проверить на реальных устройствах — всё измеренное здесь получено в
   headless-браузере с эмуляцией размеров экрана.
7. При необходимости перекодировать видео в MP4 — здесь доступен только
   WebM/VP8 (в сборке браузера минимальный ffmpeg без H.264). Команда
   конвертации — в `store/MEDIA.md`. Сами ролики записаны: `store/video/`.
8. Заполнить карточку из `store/card-ru.md` и `store/card-en.md`, загрузить
   `store/icon-512x512.png`, `store/cover-800x470.png` и скриншоты из
   `store/screenshots/`.
