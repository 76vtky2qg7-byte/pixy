# Черновик — параметры игры

Страница «Черновик» в консоли Яндекс Игр. Заполняется первой, до описаний.
Содержимое блока кода — то, что выбирается или вписывается в поле.

---

## Версия

```
1.0.0.0
```

В форме по умолчанию `0.0.0.1`. Это первый публичный релиз, поэтому `1.0.0.0`
честнее.

## Поддерживаемые платформы · обязательное

```
Компьютеры, телефоны, планшеты
```

Отметьте всё, что есть в списке. Игра проверена и на телефоне, и на компьютере:
сенсорный джойстик и WASD/стрелки работают, вёрстка проверена на десяти
размерах экрана от 320×568 до 1920×1080.

## Ориентация · обязательное

```
Любая
```

Игра рассчитана на вертикальный экран, но горизонтальный тоже работает —
композиция перестраивается, ничего не обрезается.

## Игра переведена на · обязательное

```
Русский, Английский
```

Оба языка полные: 222 строки интерфейса, ни одной непереведённой. Это
проверяется автоматически при каждой сборке (`npm run audit:static`).

### Про сообщение «язык управляется через Yandex Games SDK»

Оно стоит в форме рядом с этим полем, и здесь всё в порядке. Адаптер читает
`environment.i18n.lang` при инициализации SDK и запускает интерфейс на этом
языке — см. `src/platform/yandex.ts`. Если модератор откроет игру с русской и
с английской локалью, он увидит разные языки. Переключатель в настройках тоже
есть, выбор сохраняется.

Если SDK недоступен, язык берётся из браузера (`src/platform/mock.ts`,
`NullPlatform`). Раньше в этом случае всегда включался русский — исправлено,
покрыто `src/tests/platform.test.ts`.

## Игра использует облачные сохранения

```
Включить
```

Игра действительно вызывает `player.getData` и `player.setData`, когда игрок
авторизован. Без авторизации прогресс пишется локально и игра проходится
полностью.

## Отсроченная публикация

```
Выключить
```

Выключить, если не нужна конкретная дата выхода.

## Хочу подключить AI-описания

```
Выключить
```

В форме включено по умолчанию. Тексты карточки написаны вручную — если
оставить переключатель включённым, платформа может подставить свои.

## Комментарий разработчика

Это поле читает модератор, поэтому здесь сразу отвечено на то, что он будет
проверять.

```
Игра на русском и английском. Язык берётся из Yandex Games SDK: адаптер читает environment.i18n.lang при инициализации и запускает интерфейс на этом языке. Переключить язык вручную можно в настройках игры, выбор сохраняется.

Авторизация не требуется — без неё игра проходится полностью, прогресс пишется локально. При авторизации прогресс дополнительно синхронизируется через player.getData/setData.

Реклама: только добровольная за удвоение награды на экране итогов, не чаще одного раза за контракт, и одна межстраничная в паузе после итогов. Ни один уровень не требует просмотра рекламы. Если SDK недоступен, рекламные кнопки не показываются, игра продолжает работать.

Внутриигровых покупок в этой версии нет: каталог не настроен, раздел скрыт.
```
